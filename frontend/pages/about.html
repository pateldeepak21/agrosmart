📖 About This Project

Sustainable Fertilizer Usage Optimizer — Minor Project

🎯 Project Objective

AgroSmart is a web-based decision support system designed to help farmers optimize fertilizer usage. By analyzing crop type, soil properties, seasonal conditions, and prior crop residue, it calculates the precise Nitrogen (N), Phosphorus (P), and Potassium (K) requirements — reducing waste, cutting costs, and protecting the environment.

🌾 NPK Calculation Logic

The fertilizer requirements are calculated using agronomic formulas:

Step 1: Get base NPK for crop (e.g., Wheat: N=120, P=60, K=40 kg/ha)
Step 2: Apply soil modifier (Sandy +15%, Clayey −10%, Black cotton −15%)
Step 3: Subtract prior residue contribution (Legume: −30 kg N)
Step 4: Apply pH correction (pH <5.5: reduce N by 15%, P by 30%)
Step 5: Apply moisture correction (moisture >65%: reduce N by 10%)
Step 6: Calculate sustainability score based on organic use, pH, moisture
